# MESA-SSL — Mechanism-Grounded Self-Supervised Learning

Research repository for mechanism-grounded explainable self-supervised representation learning, concept identification and human-governed model adaptation (HCLM).

The source code, benchmark results, reproducibility audits and experiment workflows are maintained in this **independent repository**, separate from forecasting/anomaly detection projects.

The `MESA_SSL/` directory contains the research Python package and result archives. GitHub Actions workflows are located in `.github/workflows/`.

Original benchmark and optimization outcomes are documented in `MESA_SSL/RESULTS.md`. The benchmark archive includes source-level implementation distinctions and limits of comparability.
